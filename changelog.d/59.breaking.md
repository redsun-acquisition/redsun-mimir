The positioner of the example sessions shows each stage's axes in a box named after the stage's `axis` map: `XY-axis`, `Z-axis` and `stage-axis`, titled `XY / axis` and so on, in place of `XY`, `Z` and `stage`. Positions saved under the old names no longer match a box; move the stage to each one again and save it. An `include` list in a session file uses the new names.

```yaml
# before
presenters:
  motor_ctrl:
    include: [XY]

# now
presenters:
  motor_ctrl:
    include: [XY-axis]
```
